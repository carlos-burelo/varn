# Código de Conducta

Este proyecto sigue un estándar profesional simple:

1. Sé respetuoso y técnico.
2. Critica ideas, no personas.
3. Mantén el foco en hechos reproducibles y código.
4. Evita hostigamiento, discriminación y ataques personales.
5. Prefiere la claridad arquitectónica sobre la defensa de deuda técnica.

Los mantenedores pueden moderar contenido que viole estas reglas.
